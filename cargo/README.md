# {{project-name}}

A minimal `no_std` STM32 project built with [Embassy](https://github.com/embassy-rs/embassy).

- **MCU**: `{{ chip }}` - {{ core }}, Rust target `{{ rust_target }}`
- **Runtime**: `embassy-executor` + `embassy-stm32`
- **Logging**: `defmt` over RTT
- **Flash / run**: probe-rs runner (`cargo run`)
{%- if vscode_debug %}
- **Debug**: pre-configured VS Code probe-rs launch configuration
{%- endif %}
- **Linker script**: {% if use_memory_x %}self-managed `memory.x`{% else %}generated by the `memory-x` feature{% endif %}

## Requirements

- Rust stable toolchain
- probe-rs CLI: `cargo install probe-rs-tools`, or system package manager
{%- if vscode_debug %}
- Optional: VS Code with the
  [probe-rs-debugger](https://marketplace.visualstudio.com/items?itemName=probe-rs.probe-rs-debugger)
  extension
{%- endif %}

## Build and run

```bash
cargo build          # build only
cargo run            # build, flash and run (debug)
cargo run --release  # build, flash and run (release)
```

`cargo run` uses the probe-rs runner from `.cargo/config.toml` and prints the `defmt` logs.
