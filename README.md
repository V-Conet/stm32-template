# stm32-template

A minimal [cargo-generate](https://github.com/cargo-generate/cargo-generate) template for
STM32 projects built with [Embassy](https://github.com/embassy-rs/embassy).

- Works with any STM32 **F/G/H** part supported by [probe-rs](https://probe.rs):
  the Rust target, HAL chip feature and flash/debug settings are derived from the MCU name.
- `no_std`, async Embassy executor, `defmt` logs over RTT.
- Flash and run with probe-rs; VS Code debug configuration included.
- Linker script generated by `embassy-stm32` (or bring your own `memory.x`).

## Requirements

- Rust stable toolchain
- `cargo-generate`: `cargo install cargo-generate`
- probe-rs CLI: `cargo install probe-rs-tools`
- Optional: VS Code with the
  [probe-rs-debugger](https://marketplace.visualstudio.com/items?itemName=probe-rs.probe-rs-debugger)
  extension

## Usage

```bash
cargo generate v-conet/stm32-template cargo
```

You will be asked for:

| Prompt | Meaning |
| --- | --- |
| `mcu` | Part number without package suffix, e.g. `STM32G474CE` |
| `advanced` | Enables the optional prompts below |
| `ci` | Add a GitHub Actions build workflow |
| `memory_x` | Keep a self-managed `memory.x` instead of the generated linker script |
| `caching` | Use `sccache` to cache Rust build artifacts |
| `vscode_debug` | Generate VS Code build/flash tasks and probe-rs debug config |

Then build and flash:

```bash
cd <project-name>
cargo run
```
